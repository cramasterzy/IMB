IMB — Infinite Media Board
无限画布，为视频与 GIF 而生

IMB 是免费的无限画板与视觉参考软件，也是面向动态素材的 PureRef alternative。图片、GIF、视频和文字可以在同一个 infinite canvas 中自由排列、实时播放和分享。

Infinite Media Board is a free visual reference workspace with an unlimited canvas — a PureRef alternative rebuilt for video, GIF, images and text. Use IMB as an endless canvas, visual reference board or video moodboard directly in your browser.

无限画布功能 / Unlimited Canvas

自由缩放、平移、多选、吸附和排版，适合灵感收集、情绪板与视觉参考。

视频与 GIF 实时播放

多个动态素材同时播放，支持悬停声音、逐帧查看、全部暂停和继续播放。

无需安装即可分享

浏览器直接打开；也能导出可编辑或只读分享包，让没有安装 IMB 的人查看画板。

寻找 PureRef 替代方案？

PureRef 是成熟的静态参考图管理工具。IMB 延续自由参考板的工作方式，并把重点放在视频、GIF、声音、逐帧审片和跨平台网页分享上。IMB 与 PureRef 官方无关联。

Looking for a PureRef alternative for motion work? IMB combines an infinite reference canvas with real-time video, animated GIF, frame stepping, hover audio, smart layout and browser sharing.
