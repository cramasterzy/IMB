# IMB — Infinite Media Board v0.19.0

## 中文

v0.19.0 将 Infinite Media Board 正式升级为 IMB 品牌，并新增面向 macOS 与 Windows 浏览器的通用网页版，同时保留 Windows 安装版和便携版。

### 新增

- IMB 全新品牌字标与应用图标，采用精确矢量网格绘制。
- IMB Web：打开网页即可新建、编辑和自动保存画板。
- 网页版支持安装为 PWA 独立窗口，并提供离线核心缓存。
- Windows 标准安装包，包含开始菜单快捷方式和 `.imb` 文件关联。
- Windows 便携 ZIP 继续保留。
- GitHub 中英文介绍新增与 PureRef 的客观定位对比。

### 网页版说明

网页版素材与编辑结果默认保存在当前浏览器本地，不会自动上传到服务器。桌面版 `.imb` 使用内嵌 SQLite 媒体容器；网页版 v0.19.0 以浏览器本地项目和 HTML 分享包为主。

## English

v0.19.0 introduces the IMB brand and a general-purpose web edition for macOS and Windows browsers, while retaining both Windows installer and portable distributions.

### Added

- New IMB wordmark and app icon built on a precise vector grid.
- IMB Web for creating, editing, and autosaving boards directly in a browser.
- Installable PWA experience with offline core caching.
- Standard Windows installer with Start Menu entry and `.imb` file association.
- Continued Windows portable ZIP distribution.
- Objective PureRef positioning comparison in the Chinese and English GitHub documentation.

### Web edition note

Web media and edits stay in the current browser by default and are not automatically uploaded. Desktop `.imb` files use an embedded SQLite media container; IMB Web v0.19.0 focuses on browser-local projects and HTML share packages.
