# Infinite Media Board v0.18.0

## 中文

这是当前完整稳定版本，包含无限媒体画布、图片/GIF/视频/文字素材、多选整体变换、Figma 风格吸附与等间距、紧凑排版、分类排版、自包含 `.imb` 保存、跨平台 HTML 分享、合并图片导出与视频逐帧查看。

### v0.18.0 重点

- 新增“继续播放”，可在“暂停全部”后从各视频当前位置继续。
- 视频逐帧前进/后退保持原播放状态。
- 完善可编辑与只读 HTML 分享模式。
- 完善多选素材原尺寸合并 PNG 导出，视频/GIF 使用当前帧。
- 完善 5% 步进画布缩放与双击自定义百分比。
- 更新中英文图文文档和全新抽象演示素材。

下载 `Infinite-Media-Board-v0.18.0-portable.zip`，解压后运行 `Infinite Media Board.exe` 即可，无需安装。

## English

This is the current complete stable build. It includes an infinite media canvas, image/GIF/video/text items, multi-selection transforms, Figma-style snapping and equal spacing, compact/category layout, self-contained `.imb` saving, cross-platform HTML sharing, composite image export, and frame-by-frame video review.

### v0.18.0 highlights

- Added “Resume” to continue every video from its current position after “Pause all”.
- Frame stepping now preserves each video's previous play/pause state.
- Refined editable and read-only HTML sharing modes.
- Refined original-resolution composite PNG export with current video/GIF frames.
- Refined 5% step canvas zoom with double-click custom percentage input.
- Added complete Chinese/English documentation with new abstract demo assets.

Download `Infinite-Media-Board-v0.18.0-portable.zip`, extract it, and run `Infinite Media Board.exe`. No installation is required.
